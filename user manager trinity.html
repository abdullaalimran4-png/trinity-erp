📌 How to use:
  1. Paste the same firebaseConfig (ja trinity.html e diyecho) into this file's script section below.
  2. Create users here — they are pushed to the Firestore users collection (doc ID = lowercase username).
  3. Then login in trinity.html with those credentials.
  4. If Firebase config is empty, users save to localStorage (trinity_users) — open both files from the same folder/origin so login works.
  5. Default auto-created login: admin / 1234.
⚠️ Security: Keep this file private. Anyone with this file + your Firebase config can create accounts.
